# Chat Skins

Chat Skins adds selectable Codex- and Claude Code-inspired message appearances to Paseo, with a settings page for style, text size, spacing, and tool/reasoning expansion. Version 0.1 requires Paseo 0.11.2 or later and defaults to native rendering. Settings are shared by clients connected to the same host. The composer, model controls, permissions, sidebar, and window layout remain native; full-interface pixel parity is not claimed. Unsupported rich messages and tools retain host rendering. Other message-rendering plugins may take precedence. The plugin stores display preferences on the host and renders supported chat content locally; it does not send conversation data to external services. Chat Skins Settings supports English, Simplified Chinese and Hindi, including its sample preview. Its footer links to serra.dev.
